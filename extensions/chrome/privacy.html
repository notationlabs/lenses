Lenses privacy and data handling

Effective: 6 August 2026

Lenses is a local browser bridge. It does not operate an analytics, advertising, account, or remote data-collection service.

Data the extension can process

Only when enabled, local lens calls may ask the extension to process page URLs, titles, visible page content, JSON responses, screenshots, and the results of actions you requested. Those calls can use your existing website session. This can include personal or sensitive information shown by a website.

How data is used

Data is used only to complete the lens call you or your local software requested. The extension exchanges call data with the Lenses broker over loopback WebSocket connections at 127.0.0.1. It does not send this data to the extension developer. A requested website operation may, as expected, send data to that website.

Storage and retention

The extension stores your enable/disable choice locally. It stores local broker ports and temporary tab bookkeeping in browser session storage. Captured response data is held in memory and is discarded when the extension service worker, tab, or browser session ends. Other Lenses software may save output or recordings when you explicitly request it; its storage is outside this extension.

Sharing and sale

The developer does not sell extension data, use it for advertising or credit decisions, or share it with third parties. Data is disclosed only to the local software and websites needed to carry out your request, or if legally required.

Your choices

Use the toolbar action to disable the local bridge at any time. You can remove the extension to revoke its Chrome permissions and delete its local extension storage. Website account data remains controlled by each website.

Contact

For privacy questions, security reports, or deletion requests concerning developer-held data, use the repository's public issue/contact channel. Because the extension has no developer-operated collection service, the developer normally has no extension data to identify or delete.
